<p align="center"><b>Draw characters in code, and measure how close you got.</b></p>

Character Lab is an open-source lab for characters drawn entirely by code. A WebGL2 renderer draws each character's
outlines, materials and rig, with no images at render time, and the lab scores every part against its reference picture,
side by side. You can see at once whether a change to the drawing actually helped.

It is built to be driven by AI agents. Add the plugin to Claude Code or Codex, hand your agent a picture or a
description, and it creates the character, draws it until the score is good and opens it in the lab for you.

- **[CharacterLab](https://github.com/CharacterLab/CharacterLab)**: the lab, its agent skills and MCP server, and
  Captain Kite, the example character (code MIT, Captain Kite CC0)
- **Get started:** ask your agent *"Install Character Lab and show me the sample character."*
